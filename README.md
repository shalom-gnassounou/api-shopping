# 🛒 API Shopping

A small front-end project built to practice **JavaScript**, **API integration**, and **dynamic UI updates**.  
The goal of this project was to fetch product data from an external API and display it in a clean, responsive interface.

## 🚀 Features
- Fetches product data from a public API  
- Displays items dynamically using JavaScript  
- Responsive layout  
- Basic filtering or interaction (if applicable)  
- Clean and simple UI structure  

## 🧰 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Fetch API**
- **Git / GitHub**

## 📚 What I Learned
- How to fetch and handle data from an API  
- How to update the DOM dynamically  
- How to structure a small JavaScript project  
- How to improve UI consistency and responsiveness  
- Debugging and improving code readability
